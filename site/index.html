What never happens

Your dataInputs are processed in memory and discarded. Metrics are aggregate counters (tool, status, latency bucket) — no request bodies, no IPs.
AIThere is no language model in any product. Results come from official rules and data, versioned (data_version in every response), so the same input gives the same answer tomorrow.
SourcesEvery response lists the public, official sources it relied on and a data_confidence of high / medium / low, with an explicit list of anything estimated.
LegalDeadlines, payroll figures, screening hits and invoice verdicts are decision support with a disclaimer; the authority (court, FTA, ASP, ZATCA, your MLRO) decides.
DependenciesEvery library is audited for telemetry before use; images are non-root and read-only; the web crawler identifies itself (/bot).
